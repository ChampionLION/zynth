# Explorer's journal screen redesign

7 November 2026. Uses Atlas tokens; existing account authorization, EXP math, quest grading, inventory ownership and stored progression remain authoritative.

## Delivered

- **Overview:** greeting and streak hook (including zero streak), one dominant daily lesson/mission, truthful estimated reward preview, token-aware Skip entry, compact statistics, combined level/EXP goal, avatar-side attribute bars, first-mission pointer, secondary stage controls with tap/hover unlock explanations, small map footer link. No full-page map watermark. Energy and optional daily questions are inline; quick questions wait until there is completed quest history. Mobile reorders the mission before progress, avatar/attributes and stages.
- **Quest workspace:** sticky internal-scroll reading column and answer column on desktop; user-opened, dismissible reading dialog on mobile. Supplied case content is organized into problem, evidence/constraints and a reference accordion without inventing facts. Actual step completion is shown in a stepper; older answers can be reviewed while the current draft stays intact. Draft checks are local writing aids and a manual criteria check, not a replacement for grading. The existing concise-choice lesson flow remains available. Voice capture/transcription uses the existing session, with compact mic controls, recording activity/timer and privacy/language disclosure. Sticky Hint/Skip/Complete actions show reasons when unavailable. Focus mode hides navigation; elapsed time is shown without a countdown; save indicators distinguish account/device saves.
- **Mark Map:** one segment switcher with real completion counts, completed/current/next/locked/mission/landmark states, current avatar, glowing completed paths, drawn onward path on newly observed progress, pan/zoom/touch-pinch handlers, keyboard and button alternatives, recenter, locked-segment fog teaser and a collapsible legend. Checkpoint details open in a desktop panel/mobile sheet. Spring preview uses actual Foothills restoration; opening a preview grants nothing. Existing stages remain accessible from Overview without a second map navigation row.
- **Profile:** compact avatar/name/role/level header, existing customization editor, shareable PNG card, one normalized interactive radar with growth guidance, recently targeted skills with actual tier thresholds, hidden-strength silhouettes and hints derived from the existing pool/counters, compact statistics and up to three actual earned achievement badges. Settings stays in navigation.
- **Chronicle:** illustrated journal empty state, first-quest CTA and labelled example preview; filterable sample carousel; saved entries grouped by week with skill filtering and search.
- **Leaderboard:** illustrated regional empty state and quest CTA; segmented scope controls, secondary categories, region dropdown and one settings/location button; existing authoritative podium, avatars and ranks retained. A sticky You row tracks actual visibility. Rank arrows compare the current user's previously observed rank for the same scope/category/region; other participants have no stable public ranking-history identifier, so their movement is not invented.
- **Rewards:** forest overlays, ring/number burst and avatar arm celebration, badge transition, hidden-lock reveal, growing streak flame, clear changed/next steps and actual reward chips. Continue/replay still uses the existing durable acknowledgement path. Motion can be skipped; device/saved reduced motion has static presentations. Sound and haptics are opt-in and default off. Native sharing falls back to PNG download. Newly observed inventory ownership is displayed only with a known pre-submission baseline and a confirmed owned item; UI never grants cosmetics.
- **Navigation/onboarding/Home:** mobile five-tab bar with active copper treatment, collapsible desktop navigation and live mission/streak status. Onboarding has contrast-safe persistent branding, growing path/destination flag, labelled steps and explicit disabled action text; only the already-supported Still exploring direction can skip the aspiration. Starting-point reveal includes the avatar. Home contains real app previews captured with disposable data, a non-numerical founding-learners invitation (no fabricated ratings/testimonials/counts), four FAQs and readable Android download controls.

## Truthful display boundaries

The requested `+51 EXP · +1 skill point` was an illustrative UI example, not an existing fixed grant. Previews instead use the actual Excellent-grade upper-bound EXP formula and say `Skill practice`; they never promise an unconfigured skill-point reward. Hidden-strength hints describe qualifying response patterns, not a fabricated fixed number of domain quests. Next reward/unlock text uses existing thresholds. Reward labels are encouraging presentation strings; stored grades are unchanged.
